# QuesadillAI 🌮

A tiny Chrome/Edge extension that replaces every standalone instance of **AI** on webpages with **quesadillas**.

Because the internet needed this.

## What it does

QuesadillAI changes:

- `AI` → `QUESADILLAS`
- `Ai` → `Quesadillas`
- `ai` → `quesadillas`

So phrases like:

> Generative AI is transforming the future of work.

become:

> Generative QUESADILLAS is transforming the future of work.

Much better.

## Features

- Replaces standalone instances of “AI”
- Preserves capitalization
- Works with dynamically loaded page content
- Includes an on/off toggle
- Lets you choose your own replacement word or phrase
- Skips text boxes, editable fields, scripts, styles, and code blocks
- Stores your settings using Chrome sync

## Install in Chrome

1. Download this repository as a ZIP:
   - Click **Code**
   - Click **Download ZIP**
2. Unzip the downloaded file.
3. Open Chrome and go to `chrome://extensions`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the unzipped QuesadillAI folder.
7. Optional: pin QuesadillAI from the Extensions menu.

## Install in Microsoft Edge

1. Download and unzip this repository.
2. Open Edge and go to `edge://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the QuesadillAI folder.

## Customize it

Click the QuesadillAI extension icon.

You can:

- Turn replacements on or off
- Change “quesadillas” to any word or phrase
- Save your preference

Today: quesadillas.

Tomorrow: capybaras.

The infrastructure is ready.

## Notes

Browsers do not allow extensions to modify certain protected pages, including some browser settings pages and extension-store pages.

Sites with unusual rendering systems may also behave differently.

## Privacy

QuesadillAI does not collect or transmit your browsing data.

Your replacement preference is stored using the browser's extension storage.
